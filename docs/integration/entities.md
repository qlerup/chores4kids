# Integration entities

Open **Settings → Devices & services → Chores4Kids → Entities** to find the actual entity IDs on your installation.

| Sensor | State and useful attributes |
| --- | --- |
| Child points | The current point balance. Attributes identify the child and include their assigned task IDs, statuses and counts. |
| All tasks | The task count and the full task collection, including reusable templates and assigned copies. |
| Shop | Available inventory, reward details and purchase history. |
| UI settings | Shared preferences such as colors, font sizes, notification destinations and the uploaded task icon library. |

To automate an approval, find the task on the **child's sensor**. Two completions of the same chore have distinct IDs. See the [action examples](services.md).
