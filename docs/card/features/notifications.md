# Notifications

Open **Notifications** in the parent dashboard card editor. Add a notification target available in Home Assistant. Set the preferences for each recipient.

| Event | When the recipient hears about it |
| --- | --- |
| Task completion | A child marks an assigned task done. The notification identifies the task and child. |
| Shop purchase | A child buys a reward. Enable the image option for recipients who should also see the reward artwork. |

Complete a test task or buy an inexpensive reward from the child card and check the selected device. If the target is missing, confirm its notification action is available in Home Assistant. Notifications use the Home Assistant system language. See [card languages](../internationalization.md) for the separate dashboard setting.
