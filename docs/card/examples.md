# Card examples

## Parent dashboard

```yaml
type: custom:chores4kids-card
mode: admin
show_scoreboard: true
```

## Child dashboard

Create Emma in the parent view first. If the editor has not populated the picker yet, enter her name manually.

```yaml
type: custom:chores4kids-card
mode: kid
child: Emma
language: auto
```

## Recent tasks in Dutch

```yaml
type: custom:chores4kids-card

language: nl
```
